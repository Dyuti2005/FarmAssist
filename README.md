# FarmChain Assist

A farmer-friendly agricultural platform combining:
- AI Digital Twin for personalized farmer insights
- Voice-first interaction
- Multilingual support: Kannada, Hindi, English
- Personalized AI recommendations
- Agricultural marketplace for BUY and SELL
- Blockchain-based crop traceability
- QR-based Crop Passport
- Farmer and buyer profiles

## Project Overview
This project structure contains all the necessary modules to run the platform, categorized clearly into frontend, backend, AI logic, blockchain contracts, and more.
